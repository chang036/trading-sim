## 1. 網頁版（建議先玩這個）

雙擊 `trading-simulator.html`，用 Chrome / Edge 開啟。

第一次開啟是空的，按 **設定 → 載入範例資料** 可以馬上看到完整畫面；
或直接從 **交易 / 出入金** 開始：先入金 →（需要時）換匯 → 買進。

### 六個分頁

- **總覽**：總資產、現金錢包（TWD/USD）、持倉市值、累計報酬、資產曲線、配置、
  持倉明細、損益摘要（交易/匯率分開）、壓力測試（價格＋匯率情境）、風險指標。
- **交易 / 出入金**：買進/賣出、入金/出金（可選 TWD 或 USD）、TWD⇄USD 換匯、
  定期定額 DCA。買賣可勾選「餘額不足時自動換匯」。
- **行情模擬**：每檔標的可個別設定手動 / 隨機 / 即時，也能新增自訂標的。
- **交易紀錄**：完整流水帳（含幣別、錢包餘額、已實現損益、利息/配息），可篩選、搜尋、刪除重算、匯出 CSV。
- **分析**：XIRR/簡單年化、Sharpe、最大回撤、回撤曲線、月報酬熱力圖、基準對照、蒙地卡羅模擬。
- **設定**：基準幣別、匯率、交易/換匯手續費、賣出稅、現金年利率、CORS 代理、備份 / 還原、清空。

### 三種價格模式（可混用）

| 模式 | 說明 |
|---|---|
| 手動 | 自己輸入價格，完全離線、最可控 |
| 隨機 | 幾何布朗運動，可調年化報酬與波動，速度可選 5 分鐘～1 天／tick |
| 即時 | 加密貨幣：Binance（備援 CoinGecko）<br>台股 ETF：證交所每日收盤價<br>美股 ETF：Stooq |

> 美股 ETF 的即時報價常被瀏覽器的 CORS 擋住。若失敗，畫面會顯示原因並保留原價，
> 改用手動或隨機即可；進階使用者可在 **設定 → 自訂 CORS 代理** 填入自己的代理網址。

### 計算方式

- **分幣別錢包**：現金分 TWD / USD 兩個錢包；買賣一律用標的報價幣別付款。
- **換匯**：TWD⇄USD 可設定匯率與手續費；USD 換回 TWD 時認列匯率損益。
- **成本法**：持倉採移動平均成本，並保留買進當時的基準幣成本（用來拆分匯率損益）。
- **損益拆分**：總報酬 = 總資產 − 淨投入，並拆成交易損益 / 匯率損益（已實現＋未實現）。
- **DCA**：定期定額計畫在到期時以當下價格建立買進紀錄；歷史補跑以當下價格近似。
- **XIRR / 基準 / 蒙地卡羅**：XIRR 由入出金現金流與當前估值計算；基準與蒙地卡羅為參數近似模擬，不是預測。
- **淨投入**：以入金/出金當下匯率換算成基準幣。利息/配息計入資產，不計入淨投入。
- 出金可讓錢包變負數（模擬先買後補錢），系統只提醒、不阻止。

### 資料保存與 PWA

資料存在瀏覽器的 `localStorage`（`twsim.v3`），不會上傳。換電腦或想備份請用
**設定 → 備份 JSON**，要還原就按 **還原 JSON**。

HTML 含 manifest 與行動裝置 meta，可加入手機主畫面；Service Worker 快取在 HTTP(S) 環境下啟用（`file://` 直接開啟時不啟用）。

## 2. Excel 版

> Excel 版是**基準幣別總帳**視圖：可算出入金、買賣與損益，但不分開追蹤 TWD/USD 錢包與匯率損益；完整多幣別請用網頁版。

開啟 `投資模擬器_範本.xlsx`，六個分頁：

- **儀表板**：自動彙總總入金、總出金、現金、持倉市值、總資產、報酬率、已實現／未實現損益
- **出入金**：日期、類型（入金／出金）、金額、備註
- **買賣紀錄**：日期、類型、標的、數量、成交價、報價幣別、匯率、手續費、備註
- **持倉**：數量與平均成本自動帶入；只要更新「現價」就會算市值與損益
- **設定**：基準幣別、匯率
- **說明**：使用步驟

規則：**黃底**是自己填，**灰底**是公式不要覆蓋。範例列有標註「範例，可刪」。
資料填到第 301 列都支援；要更多列，把最後一列的公式往下拉即可。

### 把網頁資料搬到 Excel

1. 網頁 → **設定 → 備份 JSON**
2. 在資料夾開終端機執行：

```powershell
python build_xlsx.py trading-sim-backup-2026-11-21.json
```

就會產生一份填好出入金、買賣、持倉現價的 Excel（公式照樣會自動算）。
